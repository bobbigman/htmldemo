# 替代发货功能 · HTML 演示原型

## 怎么打开

用 Chrome 双击本目录下的 `index.html` 即可，无需服务器、无需联网。全部样式与脚本内联在同一文件，断网也能用。

建议窗口宽度 ≥ 1280（目标 1440×900）。

## 演示剧本（约 2 分钟）

1. 打开后默认在**替代发货主控台**（金蝶菜单瘦壳）：左侧模块「替代发货」，中间两个入口——业务单据「发货指令单」、基础资料「替代方案」。
2. 点**【发货指令单】**进入作业页，看单据头和「发货明细」3 行（N-101 / N-205 / M-330）。
3. 点工具栏**【替代发货】** → 近全屏匹配结果；表下红字提示 M-330 未维护方案。
4. 工具栏点**【新增】** → 表格直接多一行浅黄「手工临时」（无弹窗，可改主料/替代料/数量）；点选不要的行再点**【删除】**去掉。
5. 下方「本次匹配规则」默认勾选 → **保存** → 切到「替代发货明细」，当前表内行一并写入（临时**不写回**基础资料）。
6. 把某一行替代数量改成 **25** → 立刻报错「替代数量不能大于发货数量」→ 改回合理值。明细页仍可用**【新增行】/【删除选中行】**继续改。
7. 点**【生成组装拆卸单】**：子件可用库存不够会直接拦截（如把某行数量改大或给 `N-101-B` 填数量）；够则出预览 → **保存** → 「组装拆卸单」页签出现单据，按钮变为「已生成 STK-20261115-001」。
8. 点**【返回主控台】** → 再进**【替代方案】** → 列表 3 条 → 双击 TY-001 → 看两条替代料明细。

单据页底部浅黄提示条可点 × 关闭。「退出」回到主控台。

## 已经做了什么

- **替代发货主控台**：默认首页，挂「发货指令单」「替代方案」两个菜单入口
- 发货指令单：单据头、发货明细、替代发货明细、组装拆卸单三个页签
- 三个弹窗：替代方案匹配、组装拆卸单预览（近全屏，命令在标题下工具栏）/ 新增临时替代（小窗仍底部确定）
- 匹配弹窗工具栏：【新增】直接加行（无弹窗）、【删除】删当前选中行；无勾选列；明细页仍可增删
- 口径提示放在单据页底部 / 匹配结果表格下方，文案从简
- 替代数量按「同一主物料合计」校验；临时原因必填
- 生成组装拆卸单时：子件可用库存不够则拦截（匹配写入仍不因库存卡单）
- 替代方案基础资料：列表查询、编辑（增删行）、删除（内存，刷新恢复）
- 视觉按金蝶云星空 Web 主控台 + 表单观感做的离线壳

## 没做什么（会上未定 / 本 Demo 刻意不含）

- 不接后端、不登录、不真实落库
- 不做完整星空全模块树（仅「替代发货」瘦壳）
- **组装拆卸单保存后，不考虑与 WMS 对接**（扫码出库、出库单/应收携带替代信息）
- 分批发货：本批要发多少，数量就先填对，再组装（不做出完货再回头改数量）
- 不做销售出库单、应收单
- 不做库存卡单（匹配时库存仅展示参考，不挡取数）
- 不写金蝶 BOS 插件 / SQL / WebAPI

## 口径说明（业务蓝图 3.1）

1. 【替代发货】按业务蓝图 3.1 执行：匹配替代方案 + 获取可用库存，一并返回「替代发货明细」。
2. 可用库存 = 即时库存 − 已被占用，取的是单据头库存组织（演示为「诺飞·成品仓」）下的数。
3. 库存只展示和提示，不拦截写入与出库；与会议「无需校验库存是否充足」不冲突——不校验的意思是「不用库存卡单」，不是「不取库存数」。
4. 匹配结果可勾选确认；临时替代可在匹配弹窗补一行，也可在「替代发货明细」新增；均不写回替代方案基础资料。

## 已知限制

- 数据全在浏览器内存，刷新页面即恢复初始状态
- 「保存 / 提交 / 审核」只 toast「演示环境不落库」
- 匹配时故意让 M-330 取不到方案，用于演示「未维护」红字路径（TY-003 仍在基础资料列表里可见）
- `N-101-B` 可用库存模拟为 0，用于演示「无可用仍可写入」
