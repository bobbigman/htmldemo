一页看清：金蝶字段 → AMOS 字段，报文里到底传什么。物料/数量/供应商等业务字段不进 JSON，由 AMOS 按身份去金蝶账套自取；要对齐业务字段请到各「同步字段」细表。
四接口共用外层信封：id / type / schemaVersion / occurredAt / subject / sequence / data。下表只列「金蝶有对应来源」或「金蝶要拼出来」的关键行。
A-003 · 采购申请同步 · inquiry.requested
金蝶侧 AMOS 报文路径 必填 怎么传
单据头 BillHead.FID
单据内码		 subject.pid
data.selected[].requisitionId		 是 写入 JSON。身份，不是单号。
明细 FEntity.FEntryID
分录内码		 data.selected[].entryId 是 写入 JSON。勾选哪些明细就传哪些。
（金蝶拼，非 XML 字段） data.title 是 写入 JSON。询价标题，按业务规则拼。
单据头 BillHead.FBillNo 等业务字段 —（不进本报文） — AMOS 读账套 用上面 FID/EntryId 自取。细表见 申请同步字段
A-007 · 采购订单同步 · order.published
金蝶侧 AMOS 报文路径 必填 怎么传
单据头 BillHead.FID
单据内码		 subject.pid
data.orderIds[]		 是 写入 JSON。可一批多个订单 FID。
（可选，建议省略） data.requestId 否 一般不传；幂等靠请求头 Idempotency-Key。
单据头 FBillNo / 供应商 / 明细物料等 —（不进本报文） — AMOS 读账套 细表见 订单同步字段
A-REQ-DEL · 采购申请删除 · requisition.deleted
金蝶侧 AMOS 报文路径 必填 怎么传
原单 BillHead.FID（删前留存） subject.pid
data.requisitionId		 是 写入 JSON。删掉以后也要还能对上原单。
固定值 PUR_Requisition data.formId 是 写入 JSON。表单标识。
删除范围（整单 / 勾选明细） data.deletionScope 是 document=整单；entries=部分明细。
明细 FEntity.FEntryID（删前留存） data.entryIds[] 条件 仅 entries 时传；整单时禁止传。
金蝶侧删除版本（持久递增） data.sourceVersion / sequence 是 同一 FID 递增；不可用随机数。两处数值相同。
删除业务时间 data.deletedAt 是 ISO8601 含时区；不得晚于 occurredAt。
本次删除操作稳定编号 data.operationId 是 重发不换号；同步日志靠它补发。
原单 BillHead.FBillNo data.billNo 否 可选，方便按单号查日志。
当前操作用户 data.operator.sourceUserId
data.operator.displayName		 条件/否 有 operator 对象时 sourceUserId 必填。
细约束与会议勾选见 申请删除字段
A-PO-DEL · 采购订单删除 · order.deleted
金蝶侧 AMOS 报文路径 必填 怎么传
原单 BillHead.FID（删前留存） subject.pid
data.orderId		 是 写入 JSON。订单身份。
固定值 PUR_PurchaseOrder data.formId 是 写入 JSON。
删除范围（整单 / 勾选明细） data.deletionScope 是 document / entries。
明细 FPOOrderEntry.FEntryID（删前留存） data.entryIds[] 条件 仅部分明细删除时传。
金蝶侧删除版本（持久递增） data.sourceVersion / sequence 是 同申请删除规则。
删除业务时间 data.deletedAt 是 ISO8601。
本次删除操作稳定编号 data.operationId 是 重发不换号。
原单 BillHead.FBillNo data.billNo 否 可选追踪。
细约束见 订单删除字段
公共信封（四接口都有）
金蝶侧怎么来 AMOS 报文路径 必填 怎么传
金蝶生成的通知编号 id 是 稳定；重发沿用同一 id。
按接口固定 type 是 inquiry.requested / order.published / requisition.deleted / order.deleted
固定 schemaVersion 是 当前为 1。
发送时刻 occurredAt 是 ISO8601。
单据类型 + FID subject.type / subject.pid 是 申请=purchase-requisition；订单=purchase-order。
请求头令牌 / 幂等键 Header Authorization
Header Idempotency-Key		 是 不在 JSON 体内；连接配置页维护令牌。
业务字段（物料、数量、状态…）对照 → 各「同步字段」细表；本页只管报文怎么组。
