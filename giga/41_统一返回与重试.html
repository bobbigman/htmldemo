四个接口成功均返回 HTTP 202 Accepted。202 只表示通知已持久接收，不代表询价创建/订单更新/删除处置完成。本期不要求金蝶轮询或接回调。
成功响应字段
字段类型含义会议结论
eventIdstring请求 id 原值
recordPidstringAMOS 通知接收记录编号
duplicateboolean是否此前已接收；不表示业务已完成
失败与重试口径
HTTP含义金蝶处理会议结论
400参数不合法修正后重发，不原样无限重试
401令牌问题联系 AMOS 核对令牌
403授权不允许联系 AMOS 核对授权
409同号不同内容核对原请求，勿覆盖旧编号
413体过大分批；需双方补具体大小上限
429 / 5xx / 超时临时故障或结果未知退避重试同一报文；间隔与告警联调前定
成功示例
{ "eventId": "kd-inquiry-example-001", "recordPid": "AMOS_NOTIFICATION_RECORD_ID", "duplicate": false }
收到 202 + 合法 JSON 即可结束本次调用并记日志。
