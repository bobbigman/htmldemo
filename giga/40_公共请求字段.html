两套通道: JSON vs AMOS 读账套
「AMOS 读账套」是什么意思？要不要我们把这些字段写进 JSON?
不需要。金蝶调第三方时，事件 JSON 只传身份（如 FID、明细 EntryId、title）。
物料、数量、状态、供应商等业务字段，由 AMOS 用事先配置好的金蝶连接（WebAPI/账套账号）自己去金蝶里读最新单据。
因此下表分两色：写入事件 JSON=我们要组的报文；AMOS 读金蝶账套=双方要对齐的金蝶字段，金蝶不用塞进 POST JSON
