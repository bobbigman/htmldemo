# 金蝶 × AMOS 采购对接 · 字段级演示

用途：项目会议演示；列表页视觉对标金蝶云星空。

依据：

- `docs/采购模块同步功能.csv`
- `.cursor/skills/blueprint-static-html-demo`
- `.cursor/skills/kingdee-amos-sync-menu`
- 飞书《金蝶与 AMOS 采购接口文档（字段级）》

## 打开方式

```bash
cd demo
npx --yes serve .
```

浏览器打开提示的本地地址，进入 `index.html`。也可直接打开 `00_登录页.html`。

## 演示形态（对标星空首页菜单墙）

壳：顶栏 + **左导航（供应链向下展开子项）** + **右侧菜单墙**（点开后才进单据页）。

- **左**：我的 / … / **供应链** → 其下同列展开：采购管理 / 销售管理 / 信用管理 / 库存管理 / 组织间结算 → 再接下一级领域…
- **右·首页**：对标星空采购管理菜单墙（分组 + 菜单条）；可点项进演示页


采购申请分组可点：**采购申请单列表**；**AMOS连接配置**（红圈）；**同步日志**（红圈）。  
订单处理可点：采购订单列表、采购订单变更单列表。  
页底：**报文字段对照**（金蝶字段 ↔ AMOS 路径，看报文怎么传）；**字段分析**（会议勾选总览）。

默认路径：供应链 → 采购管理 → **菜单墙首页**。

列表组合菜单：**同步到AMOS / 取消同步标记 / 同步报文**。

## 字段来源

- 金蝶：`docs/kingdeeXml/采购申请单.xml`、`采购订单.xml`
- 第三方：飞书《金蝶与 AMOS 采购接口文档》事件字段（A-003 / A-007 等）

## 会议用法

1. 打开即见采购管理菜单墙；在 **采购申请** 分组点红圈进配置/日志。
2. 点采购申请单列表 / 采购订单列表演示审核与同步到AMOS。
3. 页底先开「报文字段对照」看金蝶↔AMOS 怎么组报文；再开「字段分析」对齐 CSV 细表。
